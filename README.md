CCNA VLAN, EtherChannel, HSRP, DHCP, DNS & Web
Cisco Packet Tracer project covering VLANs, EtherChannel, HSRP, DHCP, DNS, and Web Server configuration.

1.VLAN
Configured VLANs to separate the network into different logical segments.

2.EtherChannel
Combined multiple physical links between switches into a single logical link to provide redundancy and higher bandwidth.

3.HSRP
Configured HSRP between routers to provide gateway redundancy and maintain connectivity if the active router fails.

4.DHCP
Configured DHCP to automatically assign IP addresses and network settings to client devices.

5.DNS
Configured DNS to resolve domain names to IP addresses.

6.Web Server
Configured a Web Server and enabled clients to access the hosted website through the network.
